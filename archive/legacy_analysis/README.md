# Historical analysis

These files are retained for provenance and are not the current analysis:

- `analyse_results.py`: earlier final-window score summaries, unpaired tests,
  and hard-coded literature expectations. It does not implement the proposal's
  primary paired AUC analysis.
- `results_summary.csv`: historical three-game output. It is not regenerated
  by the current analysis; its significance/difficulty columns are historical.

Run `python -m analysis.review` from the project root for the maintained workflow.
See [the methodology review](../../docs/RESULTS_REVIEW.md) for the differences.
