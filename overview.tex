\section*{Summary}
This draft reports the corrected trial (\texttt{corrected-rct-01}): four
extensions of DQN, each compared with standard DQN on the same 30 sampled
hyperparameter configurations, in four MinAtar games (600 completed runs).
The primary outcome is the area under the evaluation learning curve (AUC).

\begin{itemize}
    \item \textbf{Averaged DQN} has a significantly higher AUC than DQN in
    Asterix ($+57.5\%$), Freeway ($+20.9\%$) and Space Invaders ($+19.5\%$).
    It does better on 24--26 of the 30 configurations in each of these games.
    \item \textbf{Double DQN} is significantly better only in Space Invaders
    ($+11.4\%$). Its other differences are not significant.
    \item \textbf{PER} is significantly worse in Freeway ($-35.3\%$) and
    Space Invaders ($-50.0\%$). Fixing the priority-bookkeeping bug barely
    changed PER (see \hyperref[sec:per-fix]{\emph{Did the PER fix change PER?}}), so the bug did not cause the deficit.
    \item \textbf{$n$-step DQN} is significantly worse in Asterix ($-80.0\%$),
    Freeway ($-59.4\%$) and Space Invaders ($-21.0\%$). In Asterix it hardly
    learns (Figure~\ref{fig:learning-curves}).
    \item \textbf{Breakout} shows no significant difference for any extension.
    All four 98.75\% intervals include zero. This does not show that the
    extensions are equivalent there.
    \item All nine significant results under the planned per-game threshold
    remain significant with Bonferroni correction across all 16 comparisons,
    and the Wilcoxon signed-rank test agrees with each of them.
\end{itemize}

\section*{Design}
\textbf{Arms.} DQN (control), Double DQN, prioritised experience replay
(PER; proportional, $\alpha=0.6$, $\beta_0=0.4$), $n$-step DQN ($n=3$) and
Averaged DQN ($K=10$).

\textbf{Individuals.} 30 individuals were drawn once from the shared
hyperparameter space (learning rate, buffer size, batch size, target-update
interval, $\varepsilon$-decay length, network depth). Each has its own
training seed. Every arm trains the same 30 configuration--seed pairs, so the
comparisons are paired. The statistical unit is the individual. The ten
evaluation episodes and the 100 checkpoints are repeated measurements, not
replicates.

\textbf{Protocol.} Each run trains for 5 million frames. Every 50,000 frames
the greedy policy is evaluated over ten episodes with fixed seeds. AUC is the
trapezoidal integral of mean evaluation return from 50,000 to 5,000,000
frames, reported in $10^6$ return\,$\times$\,frames.

\textbf{Inference.} Each treatment is compared with DQN using a two-sided
paired $t$-test on the 30 AUC differences. The proposal sets a Bonferroni
threshold of $\alpha = 0.05/4 = 0.0125$ within each game, with matching
98.75\% confidence intervals.

\section*{Data and provenance}
\begin{itemize}
    \item Double DQN, PER, $n$-step and Averaged DQN results come from
    \texttt{Results/corrected-rct-01}.
    \item The corrected run did not include DQN, so the DQN results come from
    the original run (\texttt{Results/original-run-2026-09}). This is valid
    because the corrected run reproduced every Double DQN, $n$-step and
    Averaged DQN trajectory bit for bit. Between the two runs, the only code
    change that affects learning is the PER fix.
    \item $n$-step Freeway individuals 18--29 also come from the original run,
    because the corrected job failed at start-up. Individuals 0--17 match in
    both runs. Restricted to individuals 0--17, the effect is $-53.3\%$
    ($p = 2.4\times10^{-5}$), which supports the full-sample result.
    \item Every stored AUC recomputes exactly from its trajectory. Each
    individual has the same seed and configuration in every arm. Independent
    recomputation reproduces all 16 paired tests.
    \item Seaquest is excluded. In every arm, a greedy evaluation episode
    stalled beyond the 100,000-step guard, which aborts the run on purpose.
\end{itemize}

Table~\ref{tab:paired} and Figure~\ref{fig:paired-effects} show the
comparisons. Under the per-game threshold, nine of the 16 comparisons are
significant: Averaged DQN in three games, Double DQN in one, PER in two and
$n$-step DQN in three. Two comparisons are close but not significant:
Double DQN in Asterix ($+28.2\%$, $p=0.048$) and Double DQN in Freeway
($-8.5\%$, $p=0.014$). Their intervals include zero.

In absolute terms, the differences between arms are largest in Freeway and
Space Invaders. Breakout curves overlap almost entirely
(Figure~\ref{fig:learning-curves}). The variation between individuals is
large. In Asterix and Space Invaders, the spread of AUC within an arm is
comparable to the differences between arms (Figure~\ref{fig:auc-distributions}).
This is why the paired design matters.

\section*{Robustness of the main results}
\begin{itemize}
    \item \textbf{Multiplicity.} The proposal fixes the family at four
    comparisons per game. If the family is all 16 comparisons
    ($\alpha = 0.003125$), all nine findings still hold. The closest is
    Double DQN in Space Invaders ($p = 0.0029$).
    \item \textbf{Normality.} Shapiro--Wilk flags the paired differences
    ($p<0.05$) for $n$-step in Breakout, Asterix and Freeway, PER in Asterix
    and Freeway, and Double DQN in Space Invaders. Each flagged significant
    result is matched by the Wilcoxon signed-rank test. The flagged
    non-significant comparisons stay non-significant under it.
    \item \textbf{Other endpoints.} With mean return over the last ten
    evaluations, eight of the nine findings remain significant, all in the
    same direction. The exception is $n$-step in Space Invaders ($-12.1\%$,
    $p=0.048$). Double DQN in Asterix also becomes significant ($+53.9\%$,
    $p=0.007$). With return at the final checkpoint alone, which is a single
    noisy evaluation, four of the nine remain significant. These are
    exploratory secondary endpoints.
\end{itemize}

\section*{Did the PER fix change PER?}\label{sec:per-fix}
The original run used a PER implementation with a bug in how maximum
priorities were tracked. The corrected run retrained PER on the same 30
individuals with the bug fixed and left all other code unchanged.

\begin{table}[htbp]
    \centering
    \caption{PER mean AUC ($10^6$) before and after the fix, with the paired
    $t$-test between the two runs on the same individuals.}

        Game & Before fix & After fix & Change & Paired $p$ \\
        \midrule
        Breakout & 65.29 & 66.69 & $+2.1\%$ & 0.58 \\
        Asterix & 14.12 & 13.99 & $-0.9\%$ & 0.89 \\
        Freeway & 114.11 & 103.36 & $-9.4\%$ & 0.27 \\
        Space Invaders & 80.97 & 84.39 & $+4.2\%$ & 0.43 \\
        \bottomrule

None of the changes is significant (Table~\ref{tab:per-fix}), and the
conclusions about PER versus DQN are the same before and after the fix. So
the PER deficit in Freeway and Space Invaders comes from something other
than the bug. Candidates include the interaction with the shared training
recipe (MSE loss, RMSprop) and the importance weights. The Space Invaders curve drops in the first few hundred thousand
frames and stays at about half of DQN's level
(Figure~\ref{fig:learning-curves}). The loss histories being regenerated
are needed to examine this.

\section*{Limitations and open items}
\begin{itemize}
    \item \textbf{PER loss histories (in progress).} Individuals 0--12 of PER
    have results but no loss log. They are being retrained with identical
    code, environment and seeds. A rerun is accepted only if its evaluation
    curve matches the reported one exactly. PER has already reproduced
    exactly across separate cluster jobs.
    \item \textbf{Loss coverage elsewhere.} DQN loss histories exist only in
    the original run's logs. Commit \texttt{d697076} removed them from the
    working tree, but git history still has them. In the corrected run,
    Double DQN Breakout has loss histories for only 2 of 30 individuals.
    Loss figures must state which individuals they cover.
    \item \textbf{Seaquest} is excluded (see Data and provenance). Reporting it
    would need a protocol change, such as a capped evaluation that records
    partial scores, applied to every arm.
    \item \textbf{Scope.} Each configuration has one training seed, so
    sensitivity to the configuration cannot be separated from seed variation.
    The training recipe is shared across arms and is not each paper's
    published recipe. The results concern these variants under this recipe
    on MinAtar.
    \item \textbf{AUC} covers only the observed interval and mixes learning
    speed with final level. The learning curves and the secondary endpoints
    should be read alongside it.
\end{itemize}

\section*{Next steps}
\begin{enumerate}
    \item Finish the PER loss rerun, check it, and add PER loss diagnostics:
    the weighted loss, unweighted TD error, and importance-weight statistics,
    which are already logged.
    \item Run exploratory analyses that need no new training. These include
    whether the treatment effects depend on the hyperparameters (e.g.\
    $n$-step against buffer size and learning rate), ranking stability
    across AUC, the last-ten-evaluation mean and the best checkpoint, and
    paired-bootstrap intervals.
    \item Decide on the inference family (per game or across games) and on
    how Seaquest is reported, then freeze the analysis plan before writing
    the results chapter.
\end{enumerate}
